Self-taught developer from Bangladesh. I build games, Android apps, Minecraft mods, and a few things that probably shouldn't exist, like my own programming language. I learn by shipping stuff, breaking it, and fixing it.

- Building things in **Python** and **Kotlin**
- Making games in **Godot**
- Modding **Minecraft** with NeoForge and Forge
- Currently deep into low-level stuff: a compiler written in x64 assembly
